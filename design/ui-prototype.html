✦ 设计说明（v3）

信息架构（按需求重排）

  • 左导航仅 4 项：首页 / 工具集 / 测试报告 / 设置（设置点击弹窗，不占页面）。
  • 首页 = 简介 Hero + 常用工具卡（目前 2 个工具，与工具集数据同源）。
  • 工具集 = 全部工具卡片（后续新增工具只需注册一条元数据）。
  • 测试报告 = 列表管理：行点击查看详情；多选/全选删除；同类型报告可「对比」（新窗口）。
  • 不显示「近期报告」。

向导式任务流

  • 峰值采样：配置页（设备/应用/备注/间隔/高级选项）→ 开始采样 → 实时页（趋势图 + 实时统计 + 结束按钮）→ 结束 → 自动落盘并跳转报告页。
  • 内存快照：配置页 → 开始抓取 → 抓取中（Spinner，hidumper 单次执行提示）→ 完成 → 跳转报告页。
  • 顶部步骤条（1 配置 / 2 采集 / 3 报告）标明当前阶段；实时采样期间顶栏出现可点击的「采样中」芯片，随时回到实时页。

报告详情页

  • 顶部：类型图标 + 包名 + 类型标签 + 备注胶囊（可编辑）+ 操作（打开目录 / 查看 hidumper 原文 / 导出）。
  • 环境信息网格：采样时间（起~止）、设备型号+序列号、系统版本/API、PID、时长、点数、采样间隔、运行内存、分辨率。
  • 趋势报告：概览统计 + 全宽趋势图；快照报告：概览统计 + 分类条形图 + 附加指标 + 可排序明细表。

报告对比（新窗口）

  • 列表勾选后底部出现对比条；类型不一致时按钮禁用并提示原因。
  • 趋势对比：同一坐标系叠加多份报告的 Total Pss 曲线 + 峰值/均值/结束值/增长量差异表。
  • 快照对比：各快照 Total Pss 并排列 + 分类差异表（相对基准的增减，红绿着色）。
  • 原型用全屏弹窗模拟独立窗口；落地时用 BrowserWindow 打开 compare.html，经 IPC 拉取数据。

与现状的映射

  • 主进程 / IPC / 存储层零改动；flexlayout 页签工作区退役，改为单页路由 + 独立对比窗口。
  • 设备/应用选择从全局侧栏下沉到各工具的配置页（每次任务显式确认目标，避免误采）。
